# Vylonium — Portfolio

A complete, production-ready personal portfolio website.

**Live site:** deployed on GitHub Pages.

## Pages
- `index.html` — hero, stats, featured work, services preview
- `about.html` — story, experience timeline, education, skills
- `projects.html` — filterable project archive (6 case studies)
- `services.html` — 6 services + process timeline
- `blog.html` — writing archive
- `contact.html` — contact form + direct lines

## Tech
- Pure HTML / CSS / JS — zero dependencies, zero build step
- Light professional theme, editorial layout (no card grids, no icon boxes)
- Animations: scroll-reveal, typing rotator, counters, marquee, tilt-on-hover, scroll progress
- Responsive, accessible, `prefers-reduced-motion` friendly
- SEO meta, sitemap, robots, custom 404

## Deploy
Any static host works. For GitHub Pages, the site publishes automatically from the `main` branch root.
