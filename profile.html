Bagaimana cara mereset PIN?
Anda dapat mereset PIN menggunakan Security Key yang telah diberikan saat pembuatan akun pada perangkat utama Anda.
Apa itu Security Key?
Security Key adalah deretan kode unik yang dienkripsi secara statis sebagai akses pemulihan tingkat tertinggi untuk identitas Anda.
Bagaimana jika akses terkunci?
Sistem secara otomatis mengunci sesi apabila terjadi kegagalan otentikasi berulang. Akses akan terbuka kembali setelah 24 jam.
